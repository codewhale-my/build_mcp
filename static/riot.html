🎮 绑定拳头账号

Riot 对服务器 IP 强制人机验证，所以后台不能直接登录。做法是 你在自己浏览器里登录一次，把结果交给后台 —— 之后长期免登录， 机器人每天都能直接查你的每日商店。推荐用①

区服（国服不支持）

① 点下面的按钮打开拳头官方登录页 （需要能访问 Riot，通常要开代理），登录你的拳头账号。

② 登录成功后，浏览器会跳到一个 打不开的 localhost 页面 —— 这是正常的（你本机没有这个服务）。 别关页面，把地址栏里那条完整地址复制下来，粘到下面：

手机上长按地址栏复制即可；地址里那段 code= 后面的一次性授权码只能使用一次，粘完就别刷新了。

备选方式（地址栏拿不到 / 只想绑 1 小时时用）

A) 贴 ssid（长期有效，但要手动翻 Cookie）： 打开 auth.riotgames.com 并登录后，按 F12 → Application / 应用 → 左侧 Cookies → 点 https://auth.riotgames.com → 认 「Name / 名称」这一列里写 ssid 的那行，复制它的 Value。
更省事的是在 Network / 网络 里随便点一条 auth.riotgames.com 的请求 → 右键 → Copy → Copy as cURL (bash)，整段文本粘进来。

B) 老的「贴登录地址」：登录成功后地址栏会停在 playvalorant.com/opt_in#access_token=…，把整条地址粘到这里 （仅 1 小时有效，过期要重新来）。

已绑定

想让机器人以后每天直接查、不用再登录？点下面按钮用「一键登录」升级为长期绑定。

链接 30 分钟内有效，只能绑到你自己的账号名下。
「一键登录」与 ssid 绑定 = 长期有效，过期自动续；「贴登录地址」= 1 小时后失效，需再要一条链接。
