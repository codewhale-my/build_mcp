🎮 绑定拳头账号

Riot 对服务器 IP 强制人机验证，所以后台不能直接登录。你在自己的浏览器登录一次， 把登录凭证交给后台：推荐用 ssid（长期有效，以后不用再登），拿不到 ssid 也可以只粘登录地址（1 小时）。

① 打开 Riot 官方登录页，登录你的拳头账号（需要能访问 Riot，通常要开代理）。

② 登录成功后取出 ssid（长期凭证），粘贴到下面一次搞定，永久免登

怎么拿 ssid？（点开看步骤）
电脑上（推荐，一次性）：
1. 浏览器按 F12 打开开发者工具；
2. 切到 Application / 应用 → 左侧 Cookies → 点 https://auth.riotgames.com；
3. 在列表里看 「Name / 名称」这一列，找到写 ssid 的那一行，复制这一行的 Value。
⚠️ 别拿错行！列表里有好几个长得像的（tdid、csid…），名字列必须是 ssid。 自查方法：ssid 的 Value 以 eyJhbGciOiJSUzI1NiIs 开头（注意 J 后面是 S）； 以 eyJhbGciOiIUzI1NiIs 开头的是 tdid，贴了没用。

更省事的替代（推荐）：在开发者工具 Network / 网络 里随便点一条 auth.riotgames.com 的请求 → 右键 → Copy → Copy as cURL，把整段文本直接粘到下面（本页会自动从里面提取 ssid，不会拿错）。

只有手机？手机浏览器读不到 ssid，只能用下面「③ 备选」的地址方式（每次要重登）。想长期免登录，借台电脑操作一次即可。
区服（国服不支持）

③ 备选（只有手机 / 拿不到 ssid）：登录成功后地址栏会停在 playvalorant.com/opt_in#access_token=…，把整条地址复制粘贴到这里。

已绑定

想让机器人以后每天直接查、不用再登录？把 ssid 粘到下面升级为长期绑定。

链接 30 分钟内有效，只能绑到你自己的账号名下。
用 ssid 绑定 = 长期有效（登录过期自动续）；用登录地址绑定 = 1 小时后失效，需再要一条链接。
